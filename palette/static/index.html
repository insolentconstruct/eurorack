How to install

  1. Unplug all CV cables. Patch your audio interface's output to IN L and set TIME to an intermediate position.
  2. Power on your system with FREEZE held down.
  3. Disconnect your speakers: the update file is loud and harsh. Close anything else that could make a sound.
  4. Play the update file. The quality LED [A] shows the level: yellow is right; turn TIME to adjust.
  5. At the end the module restarts by itself and runs the new firmware.

If all LEDs blink red, the level was wrong: press FREEZE and play it again louder. Avoid equalizers or automatic gain in the signal chain. Full steps: the Beads manual. Don't hold SEED at power-on: it resets your settings. From Beta 2 it also repairs damaged settings: if all LEDs blink fast for 3 seconds at each power-up, the module plays on defaults and saves nothing until you power on holding SEED. Recalibrate afterwards.

Module stuck at startup even after reinstalling, or the repair keeps failing? Read the storage recovery tool and its warnings first: it erases your settings and may reset your calibration.

About

For now this makes exactly the update file published with each release, so you can check it. Choosing which features your firmware has comes later.

Drizzlet is community firmware; it is not a Mutable Instruments product, so please do not contact Mutable Instruments about it.

Each update file made is counted, by version only, with GoatCounter: no cookies, and your browser's "do not track" setting is respected. Like any web request, it sees your IP address and browser.

Made by Insolent Construct; source on GitHub. The encoder is based on Mutable Instruments' (MIT), with sine and cosine from the GNU C Library (LGPL 2.1 or later).
