How to install

  1. Unplug all CV cables. Patch your audio interface's output to IN L and set TIME to an intermediate position.
  2. Power on your system with FREEZE held down.
  3. Disconnect your speakers: the update file is loud and harsh. Close anything else that could make a sound.
  4. Play the update file. The quality LED [A] shows the level: yellow is right; turn TIME to adjust.
  5. At the end the module restarts by itself and runs the new firmware.

If all LEDs blink red, the level was wrong: press FREEZE and play it again louder. Avoid equalizers or automatic gain in the signal chain. Full steps: the Beads manual. Don't hold SEED at power-on: it resets your settings.

Module stuck at startup even after reinstalling? Read the storage recovery tool and its warnings first: it erases your settings and may reset your calibration.

About

The default Drizzlet profile makes the release update file byte for byte. Each generated WAV is decoded and checked before download.

Drizzlet is community firmware; it is not a Mutable Instruments product, so please do not contact Mutable Instruments about it.

Successful builds and WAV download clicks are counted by version with GoatCounter, respecting “do not track”. Each event contains only its build or download event name; no profile or personal data is added. Requests expose your IP address and browser to the service. After your first interaction, download totals are requested from GoatCounter and api.github.com, and site visitor counts from GoatCounter; both services receive your IP address and browser. Totals include GitHub WAV downloads and may merge repeat downloads by the same visitor on the same day.

Made by Insolent Construct; source on GitHub. The encoder is based on Mutable Instruments' (MIT), with sine and cosine from the GNU C Library (LGPL 2.1 or later).
