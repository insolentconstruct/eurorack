Drizzlet Hygrostat

Makes the firmware update file for Mutable Instruments Beads in your browser. Nothing is uploaded.

Download
App image (SHA-256)
Update file (SHA-256)
Release update file (SHA-256)
Use an app image you already have

It must be the selected release's app.bin; anything else is refused.

For now this makes exactly the update file published with each release, so you can check it. Choosing which features your firmware has comes later.

Install it as described in the README. Drizzlet is community firmware; it is not a Mutable Instruments product, so please do not contact Mutable Instruments about it.

Each update file made is counted, by version only, with GoatCounter: no cookies, and your browser's "do not track" setting is respected. Like any web request, it sees your IP address and browser.
