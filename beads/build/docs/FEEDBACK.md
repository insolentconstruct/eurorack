# Options feedback

Report the pulsing page LED, knob moved, [A] colour and pulse, and expected
setting. Use the [guide](OPTIONS.md) or [README.txt](../README.txt).
Changes save after one second at rest; closing keeps them. Unused knobs do nothing.

Check green/yellow/red on your module. Listen for interruptions during saves,
including when settings memory fills and is rewritten. Desktop tests cannot
check perceived colour or physical flash timing.
