Unofficial community build of Émilie Gillet's released Beads source; not a Mutable Instruments product.

> Code provided as is, builds on a Desktop platform but not verified to build and run on a module. Install at your own risks.
>
> — Émilie Gillet

Please don't contact Émilie Gillet or Mutable Instruments about this build; report problems in [issues](https://github.com/insolentconstruct/eurorack/issues).

- `*-wav.zip`: the audio update (`.wav`).
- `*-combo.zip`: bootloader and firmware (`-combo.bin`) for ST-Link recovery.

Both zips include `README.txt` (flashing, calibration backup) and `NOTICE.txt`. Changes from earlier firmware: [CHANGES.md](https://github.com/insolentconstruct/eurorack/blob/beads-build-kit/beads/build/CHANGES.md).
